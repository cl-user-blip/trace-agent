# Orbit Search 部署手册（原创演示数据）

此文档与所有数值均为虚构工程案例，不代表真实公司的服务。

## 发布流程 deployment
Orbit Search 使用 blue-green 蓝绿部署。先向候选实例发送 5% 的流量，再检查错误率。
回滚 rollback 的触发条件为连续 3 分钟错误率超过 2%。
回滚操作由值班人员在部署平台确认；本项目的工具没有部署权限。
部署前需验证索引版本、配置校验和以及查询延迟。

## 健康检查 health check
就绪检查要求 search API 可访问，且索引版本等于 manifest 中的版本。
存活检查只验证进程事件循环，避免下游故障触发无限重启。
