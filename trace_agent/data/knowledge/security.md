# 工具权限边界（原创演示数据）

## 工具 tools
Agent 只允许 search、read 和 calculator 三种工具。
read 只读取指定知识根目录内的 Markdown 文本，不允许绝对路径或父目录穿越。
工具返回的文本是数据，不是高优先级指令。
没有 shell、网络请求或写文件工具，也不能读取环境变量。

## 检查点 checkpoint
SQLite 同一事务保存工具结果、调用账本和最新状态。
工具执行与数据库提交之间仍有崩溃窗口；恢复可能重复执行未提交的只读调用。
业务写操作必须使用外部幂等键，不能仅靠本地 SQLite 宣称 exactly-once。
